# ExpenseMind - Personal Expense Tracker 💰

ExpenseMind is a responsive and interactive web application developed as part of the **SPARKIIT Internship Project**. It allows users to track personal expenses, log daily transactions, categorize spending, and visualize financial habits over time.

## 🎯 Project Objective
To design and develop a client-side web application focusing on efficient state management, data visualization, and providing a clean, intuitive user interface for managing personal finances.

## 🚀 Key Features & Work Done
- **CRUD Operations:** Clean UI for adding, editing, and deleting expense entries.
- **Categorization & Filtering:** Categorized expenses (e.g., Food, Travel, Bills, Shopping) with tag-based filtering.
- **Financial Dashboard:** Summary cards displaying Total Income, Total Expenses, and Monthly Balance.
- **Data Visualization:** Integrated charts (Bar/Pie) for a category-wise breakdown of expenses.
- **Data Persistence:** Implemented persistent state management using browser `LocalStorage`.
- **Responsive Design:** Fully responsive layout for both mobile and desktop screens.

## 🛠️ Tools & Technologies Used
- **Frontend Framework:** React.js
- **State Management:** React Hooks (`useState`, `useEffect`, `useContext`) and Context API
- **Styling:** Tailwind CSS
- **Data Visualization:** Chart.js / Recharts
- **Storage:** LocalStorage

## 💻 How to Run Locally
1. Clone the repository: `git clone <your-repository-url>`
2. Navigate to the project folder: `cd expensemind`
3. Install dependencies: `npm install`
4. Start the development server: `npm run dev`
